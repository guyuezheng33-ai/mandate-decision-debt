每一格去哪儿看（点开）
  • 有依据页：工作项右侧 Links / Web links，或描述里的 Confluence 链接。有任一即「是」。
  • 有目标：Parent / Epic / Goal 字段有没有挂东西。
  • 目标已结束：点开目标看状态是否 Done / Closed / Cancelled。没有目标填「否」。
  • 依据页晚于开工：比两个时间——依据页右上角 Updated，vs 工作项 Activity 里第一次进 In Progress。页面更晚即「是」。
  • 改后有人确认：在页面更新之后，工作项评论 / 新链接 / 子任务里有没有人补过一句确认。
  • 同主题第二份：在该 space 搜同一主题词，有没有第二份结论或负责人不同的页面。
  • 重开后更新过：Activity 里最后一次 Reopened 之后，依据页有没有再被改过。
  • 只有一位作者：依据页右上角 Contributors，只有一个人即「是」。
  • 有第二人复核：页面评论区或页面信息里，除作者外有没有第二个人。
  • 工作已完成：状态是否 Done / Closed。
  • 重开次数：Activity 里 Reopened 的条数，没有填 0。

查不到、或要花很久才查得到的，就留空。留空的行不参与统计，不会被当成“没问题”——但要记住：留空的行也推不出结论，所以尽量把能一眼看到的先填了。
